This essay is a foundational text in reliability engineering and safety science, and its re-emergence highlights its lasting influence on how engineers think about system failures. It matters because it challenges the common assumption that failures have a single root cause and argues that complex systems inherently run in a degraded mode. **Background**: Complex systems, such as nuclear power plants, financial markets, and large software deployments, are characterized by many interacting components and tight coupling. The essay 'How Complex Systems Fail' draws on these ideas to explain that safety is a characteristic of systems, not of components, and that systems continuously adapt to handle fluctuations.

## [MartyPC: Rust-Based Cycle-Accurate Emulator Brings Early PCs to Modern Platforms](https://martypc.net/) ⭐️ 8.0/10

MartyPC is a cross-platform emulator for early 8088-based PCs, written in Rust and supporting Windows, Linux, and macOS. It targets cycle-accurate emulation of systems including the IBM PC, XT, PCJr, and Tandy 1000, with accuracy validated against test suites built from real hardware. Cycle-accurate emulation matters because many early PC programs rely on precise hardware timing, and most existing emulators approximate rather than replicate it. MartyPC's Rust implementation and hardware-validated test harnesses could set a new standard for fidelity in retrocomputing and demonstrate Rust's suitability for low-level systems programming. The developer built physical harnesses for real early CPUs so that emulation behavior, including every timing quirk, can be checked against actual silicon. The project is available on GitHub and also offers a web edition compiled to run in browsers.

hackernews · boilerupnc · Aug 23, 03:13 · [Discussion](https://news.ycombinator.com/item?id=49405816)

**Background**: Cycle-accurate emulation attempts to emulate a system at the granularity of individual clock cycles, ensuring that software using carefully timed loops or delay instructions receives the same reactions as on real hardware. It differs from high-level emulation, which often mimics software behavior rather than the underlying hardware, and typically comes at a significant performance cost. MartyPC belongs to the low-level, accuracy-first tradition seen in projects like higan or FPGA-based console emulators.

Commenters note the fuel lacks aromatics, which can cause nitrile seals in aircraft fuel systems to swell inadequately and reduce volumetric energy density. The most developed production route, HEFA, removes oxygen from vegetable oils, waste oils, or fats via hydrogenation. Still, 100% drop-in SAF is not yet ASTM-qualified, and fuels must meet strict standards for energy density, freezing point, and seal compatibility.
