## [Htmx 4.0 Released with hx-alpine-compat Extension](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released) ⭐️ 9.0/10

Htmx 4.0.0 was released on August 28, 2026, introducing new features and compatibility improvements, including the hx-alpine-compat extension that smooths over interoperability issues between htmx and Alpine.js. As one of the most visible libraries in the hypermedia-driven web development movement, a major htmx release reinforces the server-side rendering approach as a viable alternative to heavy client-side frameworks. The improved Alpine.js compatibility lowers barriers for teams that want to mix htmx's hypermedia model with reactive Alpine components. The hx-alpine-compat extension works by overriding htmx's soft-match check to ignore ID mismatches when both swapped nodes have Alpine-reactive ID bindings, and it also saves and restores Alpine component state across history navigation when used with hx-history-cache. Htmx is a small, dependency-free library (around 14k min.gz'd), but it relies on HTML attributes to extend the traditional hypermedia model.

hackernews · rmsaksida · Aug 28, 13:28 · [Discussion](https://news.ycombinator.com/item?id=49478178)

**Background**: Htmx is a lightweight JavaScript library that extends HTML with custom attributes, allowing AJAX, CSS transitions, WebSockets, and server-sent events to be used directly in markup. It traces its roots to intercooler.js, created by Carson Gross in 2013. Htmx is a key tool in the Hypermedia-Driven Application (HDA) movement, which argues that many modern web apps can be built with plain HTML plus server-rendered fragments instead of single-page application frameworks.
